# @williamthorsen/tank

The framework-agnostic core of a site-wide balance that regenerates at a configured rate, so that a site can offer an action whose cost the operator pays while the operator's spend stays bounded. The package does not contain any code yet; [the design](docs/design.md) states what it will contain.

## Scripts

Workspace scripts (`build`, `check`, `lint`, `test`, `typecheck`) are run with `nmr`, as [Running scripts](../../README.md#running-scripts) in the root README describes. Run `nmr` from this directory to list this package's scripts.
