# @williamthorsen/tank-react

React components over [`@williamthorsen/tank`](../tank/README.md): a hook that tracks the balance, a meter that fills as it regenerates, and a countdown to ready. The package does not contain any code yet; [the design](../tank/docs/design.md#react-package-williamthorsentank-react) states what it will contain.
